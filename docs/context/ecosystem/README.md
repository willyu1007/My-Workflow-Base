# Ecosystem context

Read these pages before changing a cross-repository contract or template:

1. `development-model.md` for repository roles, extraction rules, and
   arbitration.
2. `contract-distribution.md` for the supported adoption lanes and re-pin
   ritual.
3. `schema-conventions.md` for forward-only schema and contract evolution.
4. `local-port-allocation.md` for collision-free local service ports.
5. `contract-status.md` for implemented-versus-target labels and evidence.

My-Workflow-Base owns these conventions as a contract and template source. It
does not become a runtime service or a canonical data owner.
