# Verification

Record exact commands and outcomes here. A zero exit code with skipped database
tests is not database evidence.

## Required evidence

- Exact Base, Host SDK, and scenario source revisions.
- Reproduced logical hashes and integration-lock mode.
- Fresh dedicated database name, migration result, executed database test
  count, and confirmed cleanup.
- Typecheck, unit, database, build, semantic lint, and package dry-run results.
- Authorization-negative, reliability, privacy, isolation, and deletion cases.
- Default-disabled registration evidence.

Never record database credentials, secrets, PII, prompt bodies, or domain
content.
