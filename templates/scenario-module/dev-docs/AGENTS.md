# Dev Docs

Use `dev-docs/active/scenario-integration/` as the continuity bundle for the
generated scenario until the integration task is complete.

When resuming work:

1. Read `00-overview.md`.
2. Read `roadmap.md`.
3. Read `01-plan.md`.
4. Scan `05-pitfalls.md`.

Update implementation decisions in `03-implementation-notes.md` and record
commands, outcomes, revisions, hashes, and database fixture names in
`04-verification.md`. Never record secrets, PII, domain bodies, or production
activation credentials.
