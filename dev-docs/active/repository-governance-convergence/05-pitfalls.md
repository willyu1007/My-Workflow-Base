# Pitfalls

- Do not let the new global sync guess task IDs before the agreed metadata exists.
- Do not commit a worktree containing both the legacy `main/registry.yaml` hub and the new flat hub.
- Do not preserve old numbered files when they would compete with a new authority.
- Do not treat Starter continuity documents as a reusable task identity.
- Do not broaden removal of the web-workbench skill into UI token, component, or interaction work.
