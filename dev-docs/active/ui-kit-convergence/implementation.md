# Implementation

## Realization map

| Concern | Realized behavior | Key paths / entry points | Non-obvious implementation fact |
|---|---|---|---|
| Token authority | JSON source emits the consumed CSS variables. | `templates/web-workbench/tokens/base.json`, `tokens/emit.mjs`, `src/styles/tokens.css` | `tokens:check` compares generated bytes and also classifies motion roles. |
| Visual governance | Shared lint presets and design-debt tooling reject unowned literals and broad transitions. | `templates/web-workbench/lint/`, `GOVERNANCE.md` | Hosts fix their usage; kit-owned defects are not patched through host overrides. |
| Composition | Six Scene paradigms are encoded in contracts and React components. | `templates/web-workbench/src/contracts/`, `src/components/`, `PARADIGMS.md` | Controlled variants lock chrome while adapters supply scenario-neutral content. |
| Behavior evidence | Focused tests exercise stateful components and interaction constraints. | `templates/web-workbench/tests/`, `TESTING.md` | New suites are added when a component grows state, not for stateless coverage counts. |
| Published contract | Grouped exports expose contracts/components/styles and ship top-level guidance. | `templates/web-workbench/package.json`, `README.md` | Consumers supply fonts and product data; the package is not a runtime platform. |
