### Why the drift verdict was already settled

My-Chat `dev-docs/active/ui-visual-system/artifacts/phase-0/01-authority-and-values.md`
traced the identical nine warm values on its Mobile side to a
`My-Portal/styles/colors_and_type.css` lineage, showed every in-repo design
authority (including the Mobile chat bundle) uses cold-ink-on-warm-surfaces,
and repaired Mobile as a "fidelity repair, not a redesign". The workbench
carried the same nine values, its own shadows were authored against the cold
ink, and its window-bar gradient started at the reference cream — the same
internal inconsistency. Owner confirmed 2026-07-31 the warming was not
deliberate.
